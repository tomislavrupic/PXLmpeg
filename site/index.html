01 / The idea

A smaller foundation.
A wider possibility.

PXLmpeg is a native media-processing engine for M-series Macs. It brings hardware video engines, original Metal kernels, and explicit media contracts into one reusable Swift package.

The long-term ambition is a modern alternative to everyday FFmpeg workflows, with room for future AI processing. Today, we’re proving a focused set of native paths—one useful capability at a time.

02 / Working today

Small scope.
Real, working paths.

01

Native video, including HDR.

H.264 and HEVC. Main10, HLG and PQ. Supported MOV/MP4 files, with AAC copy or explicit audio drop.

VIDEO
02

Pixels on the GPU.

Original kernels rotate and resize NV12 or P010 planes, with colour metadata carried through the pipeline.

METAL
03

Copy without re-encoding.

Move supported media between MOV and MP4. Retain compressed video, audio, display transforms and HDR metadata.

REMUX
04

Explicit by design.

Bounded owned memory, cancellation, new-file output and execution receipts. A Swift library and JSON-lines CLI.

ENGINE
Early research phase

Early days.
Deliberate steps.

This is a research project in active development. The API is evolving, the format matrix is focused, and each new capability needs evidence.

We’re testing real footage and native hardware paths. Full FFmpeg compatibility, broad production readiness, and calibrated HDR display validation are still ahead.
